# How to Publish a Blog Post

> **This has changed.** The blog no longer uses MDX files — posts are now
> managed entirely from the admin dashboard and stored in MongoDB. This file
> is kept only so old links don't 404.

## Where to publish now

1. Go to `/admin/login` and sign in.
2. Click **Blog** in the sidebar → **New Post**.
3. Fill in the title, excerpt, content (Markdown), category, tags, cover
   image, SEO title, and meta description.
4. Click **Save as Draft** to keep working on it, or **Publish** to make it
   live immediately.

See the main `README.md` for full setup instructions, including how the
original 3 MDX posts were migrated into MongoDB.
